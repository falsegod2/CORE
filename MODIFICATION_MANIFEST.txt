LS-Imagine statistical reproducibility build

Base: user-provided CORE-ls-origin archive.
Algorithm modules retained: affordance-map encoder input, zoomed observation,
jump transition, jumping-step and accumulated-reward heads, intrinsic reward,
and mixed long/short imagination.

Reproducibility changes are isolated in the `reproducible` config profile and
`scripts/train_repro.sh`. Default and `minedojo` profiles remain available.

Validation performed in this build environment:
- all Python files parsed by compileall;
- configs.yaml parsed successfully;
- shell scripts passed `bash -n`;
- generated patch dry-run checked against the supplied base tree.

Full MineDojo execution was not performed here because the container does not
contain the required Minecraft/MineDojo runtime, checkpoints and Java assets.
