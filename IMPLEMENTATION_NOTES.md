# Task-Relevant Object Tokens: implementation notes

## Controlled comparison

This branch differs from DreamerV3 + MineCLIP reward only in the visual
representation path. It uses two frozen semantic signals that the existing
MineCLIP reward computation already supplies:

- task text embedding g;
- current 16-frame global video embedding m_t.

The visual feature entering RSSM is still generated by the trainable Dreamer RGB
CNN. MineCLIP features are detached and are not decoded or passed as a separate
actor/RSSM input.

Default structure:

- 16 RGB patch tokens from the final 4x4 CNN map;
- top 8 task/state-relevant candidate patches;
- 4 object queries;
- 2 object aggregation iterations;
- one task-relevant scene token;
- unchanged RSSM input dimension.

## Core equations

For RGB patches p_i, frozen task embedding g, and frozen global video semantic
m_t:

```text
u_t = LN(W_g stopgrad(g) + W_m stopgrad(m_t))
r_i = softmax(cos(LN(W_p p_i + pos_i), u_t) / tau_r)
C_t = TopM(r)
q_k^0 = learned_query_k + W_{g,k} stopgrad(g) + W_{m,k} stopgrad(m_t)
```

For each aggregation iteration:

```text
A_{k,i} = softmax_i(cos(q_k, k_i) / tau_o + beta log r_i), i in C_t
c_k = sum_i A_{k,i} v_i
q_k <- LN(q_k + MLP([q_k, c_k]))
```

The object tokens are projected back onto their attended RGB patches and added
through a conservative residual gate. Thus the baseline spatial pathway remains
available even before useful objects are learned.

## Auxiliary losses

Three low-weight terms regularize the object representation:

- coverage: object attention collectively covers task-relevant candidates;
- diversity: different object queries avoid identical patch assignments;
- semantic alignment: pooled RGB object tokens match the detached global
  MineCLIP video embedding.

Default scales are 0.02, 0.005, and 0.02. Any can be set to zero for ablations.

## Why the global semantic teacher is included

In a single-task run, the text embedding is constant and by itself can collapse
to a learned query bias. The changing MineCLIP video embedding provides a
state-dependent pretrained semantic target, making “task-relevant objects” more
than a purely nominal label while still keeping local object features grounded
in trainable RGB patches.

## Conservative initialization

`residual_scale: 0.05`, `output_init: 0.001`, and a gate bias of -2 keep the
initial encoder close to RGB-only DreamerV3. Object influence grows only through
world-model and weak auxiliary gradients.
