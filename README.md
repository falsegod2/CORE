# DreamerV3 + Global MineCLIP Gated Fusion (MineDojo)

This branch adds one representation module to the clean RGB-only DreamerV3 baseline:

```text
trainable RGB embedding
+ frozen 512-D global temporal MineCLIP embedding
+ learned residual gate
```

The reward and control settings remain unchanged:

```text
environment reward + MineCLIP progress reward
standard single-stream DreamerV3 RSSM
standard 15-step latent imagination
```

## Fusion

Let `e_rgb` be the trainable Dreamer convolutional embedding and `e_mc` the frozen MineCLIP video embedding already computed by the reward wrapper. The encoder uses

```text
r = LN(W_r e_rgb)
s = LN(W_s stopgrad(e_mc))
g = sigmoid(G([r, s]))
e = e_rgb + alpha W_o(g * V(s))
```

The final projection is initialized with a small standard deviation and the gate bias is `-2`, so training starts close to the RGB-only baseline. The MineCLIP model is frozen and no RL gradient reaches it.

The embedding is emitted as float16 to limit replay growth and converted to float32 by the world model. It is not reconstructed by the decoder and does not create an additional reward.

## Training

```bash
conda activate ls_imagine
bash ./scripts/train.sh harvest_log_in_plains
```

Use a new log directory; checkpoints and replay generated by the RGB-only baseline do not contain the new observation field.
